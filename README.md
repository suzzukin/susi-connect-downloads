# SusiConnect — downloads

Официальные сборки клиента SusiConnect. Исходный код здесь не публикуется — только файлы для скачивания.

| Платформа | Где брать |
|---|---|
| **Android** | APK в [последнем релизе](../../releases/latest); в Google Play — «SusiConnect» |
| **iOS / macOS** | App Store |
| **Windows** | установщик в [последнем релизе](../../releases/latest) *(готовится)* |

## Android

Скачайте `SusiConnect-<версия>.apk` из релиза и откройте его на телефоне. Android спросит разрешение на установку из этого источника — это нормально для файла, скачанного не из магазина.

Обновления из магазина и APK совместимы: подпись одна и та же.

## Проверка подписи

Каждый релиз содержит `SHA256SUMS.txt` с контрольными суммами. На Android:

```
sha256sum SusiConnect-<версия>.apk
```

значение должно совпасть со строкой в `SHA256SUMS.txt`.
