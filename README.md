Сборки клиента susi connect. Здесь только файлы, без исходного кода.

## Android

apk лежит в последнем релизе. Скачайте и откройте на телефоне; система спросит разрешение установить файл не из магазина.

Подпись та же, что у сборки в google play, — обновления совместимы в обе стороны.

## Контрольные суммы

    sha256sum susi-connect-android.apk
